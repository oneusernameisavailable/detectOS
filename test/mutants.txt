# Mutation catalogue for fx-detect-os.sh — see test/mutation.sh for the format.
#
# Format (fields separated by ~, which must not appear in any field):
#   ID ~ TARGET ~ DESCRIPTION ~ TEST_FILTER ~ OLD_LITERAL ~ NEW_LITERAL
#     ID           short label, printed in the report
#     TARGET       the function whose behaviour is being broken
#     DESCRIPTION  what the mutant does, in plain words
#     TEST_FILTER  bats -f regex for the cheap first pass; anything that
#                  survives this still gets the FULL suite (see mutation.sh)
#     OLD_LITERAL  exact text to find in fx-detect-os.sh
#     NEW_LITERAL  exact replacement
#
#   Literals, not regular expressions -- an earlier sed-based version of this
#   file had 9 rules that silently matched nothing, which is indistinguishable
#   from a surviving mutant. The harness now asserts OLD_LITERAL occurs EXACTLY
#   ONCE and reports BROKESED otherwise, so a stale rule can never be mistaken
#   for a coverage gap.
#
# A mutant that no test catches is a finding: either a real coverage gap, or an
# equivalent mutant (the killed branch was unreachable), which is recorded as a
# non-finding with a reason rather than treated as suite weakness.
#
# The groups mirror the threat model: A = terminal-escape / invisible-character
# defence in _os_sanitize_display, B = secret leakage in the redaction passes,
# C = DoS and symlink policy in _os_file_ok, D = ladder ordering and trust
# levels, E = quoting.
